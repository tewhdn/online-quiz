# 500 道十类信息技术题库说明

## 来源与定位

- 依据：《2027 年河北省高职单招十类职业适应性测试考试说明》中“信息技术”部分的 8 个模块，以及《计算机应用基础知识》知识点
- 生成方式：**自编 + 程序化计算**（进制转换、Excel 函数、二叉树、IP 子网、程序输出等由脚本计算正确答案，避免人工算错）
- 不含任何题库原题，不声称是官方命题或押题
- 建议使用前结合本校教材核对；如发现知识点表述与教材不一致，以教材和官方考试说明为准

> 注意：十类职业适应性测试总分 350 分，其中**物理约占 40%，信息技术约占 60%**。本题库只覆盖信息技术部分；物理题需要另行生成。

## 覆盖的知识点（示例）

- 计算机组成：五大部件、CPU、RAM/ROM、Cache、外存、输入输出、总线
- 数据与编码：二/八/十/十六进制转换、ASCII、Unicode、汉字国标码/机内码、图像与音频容量、逻辑运算、数字化、加密
- 算法与编程：算法特征、三种结构、流程图符号、机器/汇编/高级语言、编译与解释、Python 基础、程序阅读、递归
- 数据结构：线性/非线性、数组与链表、栈与队列、树与二叉树、遍历、图、查找与排序复杂度
- 信息系统与网络：网络功能与分类、拓扑、OSI/TCP-IP、协议与端口、IP/子网、DNS/HTTP/FTP/邮件、网络设备、信息安全、病毒与防火墙
- 信息处理：Word 排版与页面设置、Excel 单元格/公式/函数/排序筛选/图表/透视表、PPT 母版/动画/切换/放映
- 人工智能：图灵测试、达特茅斯会议、机器学习类型、深度学习、NLP/CV/语音、生成式 AI、伦理
- 信息社会责任：网络安全法、数据安全法、个人信息保护法、著作权、隐私、网络道德、反诈、AI 伦理

## 如何导入

### 本地开发库

```bash
npm run seed:ten-category
```

如果尚未创建管理员：

```bash
node scripts/create-admin.mjs --sqlite workers/api/.local/quiz.sqlite --username admin --password '你的密码123'
npm run build
npm run dev:local
```

### Cloudflare D1

```bash
npm run questions:import -- workers/api/seeds/ten-category-it-500.json --commit --remote --db online-quiz --status published
```

### 管理后台

「题库管理 → 批量导入」上传 `ten-category-it-500.json`，先预览，再确认导入（单次上限 1000 题，满足 500 题）。

## 重新生成 / 二次加工

```bash
npm run bank:build
```

生成脚本：`scripts/generate-ten-category-it.mjs`，题目模板与手写题分别在 `scripts/it-bank/` 下。

修改题库后建议执行：

```bash
npm run questions:validate -- workers/api/seeds/ten-category-it-500.json
npm run security:check
npm test
```
