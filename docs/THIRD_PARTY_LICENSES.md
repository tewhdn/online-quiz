# 第三方许可证说明

本项目通过 npm 依赖使用以下开源项目，未复制其源码到业务目录。

| 项目 | 版本 | 许可证 | 用途 |
| --- | --- | --- | --- |
| [Naive UI](https://github.com/tusen-ai/naive-ui) | 2.45.3 | MIT | Vue 3 组件库：菜单、下拉、弹窗、消息、分页、加载、进度、表格、主题 |
| [Lucide](https://github.com/lucide-icons/lucide) / `@lucide/vue` | 1.61.0 | ISC | 界面图标 |
| [Vue](https://github.com/vuejs/core) | 3.5.44 | MIT | 前端框架 |
| [Vue Router](https://github.com/vuejs/router) | 4.5.1 | MIT | 路由 |
| [Pinia](https://github.com/vuejs/pinia) | 3.0.4 | MIT | 状态管理 |
| [Vite](https://github.com/vitejs/vite) | 7.3.7 | MIT | 构建工具 |

## 评估但未采用

| 项目 | 许可证 | 原因 |
| --- | --- | --- |
| [shadcn-vue](https://github.com/unovue/shadcn-vue) | MIT | 需要 Tailwind，会与现有 CSS 体系冲突，改动范围过大 |
| [Vue Vben Admin](https://github.com/vbenjs/vue-vben-admin) | MIT | 完整后台框架，会替换现有工程架构 |

许可证原文可在对应仓库的 `LICENSE` 文件查看：

- Naive UI：https://github.com/tusen-ai/naive-ui/blob/main/LICENSE
- Lucide：https://github.com/lucide-icons/lucide/blob/main/LICENSE
- shadcn-vue：https://github.com/unovue/shadcn-vue/blob/main/LICENSE
- Vben Admin：https://github.com/vbenjs/vue-vben-admin/blob/main/LICENSE
