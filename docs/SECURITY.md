# 安全设计

本文档说明已实现的安全措施、关键取舍与剩余风险。**没有绝对安全**，请结合自身部署环境评估。

## 1. 资产与威胁模型

需要保护的核心资产：

1. 用户密码与会话
2. 题库正确答案（防止作答前泄露）
3. DeepSeek API Key
4. 管理员权限与操作审计
5. 用户私人学习数据（练习、错题、收藏、成绩）
6. 邀请码（防止批量注册）

主要威胁：

- 未授权访问管理接口 / 越权读取他人数据
- 通过前端绕过判分或考试时限
- 邀请码泄露、暴力枚举、并发超额使用
- CSRF、XSS、SQL 注入
- 密钥进入前端产物或日志
- AI 返回恶意/错误内容或提示注入
- 恶意文件上传（超大、压缩炸弹、伪造类型）

## 2. 认证与密码

### 密码哈希

- 算法：**PBKDF2-HMAC-SHA256**（WebCrypto 原生）
- 盐：16 字节 `crypto.getRandomValues`
- 迭代：默认 100000，可通过 `PASSWORD_ITERATIONS` 配置（10000–600000）
- 存储格式：`pbkdf2$sha256$<iterations>$<salt_b64>$<hash_b64>`
- 校验使用常量时间比较
- 禁止明文、Base64、MD5、单次 SHA-256

**为什么不是 Argon2id**：Cloudflare Workers 没有原生 Argon2id，WASM 实现的内存/CPU 开销在免费计划（10ms CPU）下不可行。PBKDF2 是当前运行环境可实际部署的经过审查方案。若触发 1102（CPU 超限）：

- 下调 `PASSWORD_ITERATIONS`（不建议低于 50000）
- 或升级 Workers Paid 以使用更高迭代次数

这是明确记录的取舍，而不是"已实现 Argon2id"。

### 注册与登录

- 用户名 3–24 字符，允许中英文/数字/`_`/`-`，唯一（`username_lower`）
- 密码 ≥8 位且同时包含字母与数字，禁止弱口令、禁止包含用户名
- 登录失败统一返回"用户名或密码错误"，用户不存在时仍执行一次 PBKDF2，降低时序枚举
- 禁用账号无法登录，且已有会话立即失效
- 注册请求中的 `role`、`isAdmin` 等字段被忽略

### 强制改密

- 管理员重置密码后：一次性初始密码只返回一次，所有旧会话失效，`must_change_password=1`
- 除 `/auth/me`、`/auth/logout`、`/auth/change-password` 外的接口返回 `403 PASSWORD_CHANGE_REQUIRED`
- 修改密码需验证当前密码；成功后撤销全部会话并签发新会话

## 3. 会话与 Cookie

- 32 字节随机令牌（256 bit），只保存 SHA-256
- Cookie：`HttpOnly`、`SameSite=Strict`、`Secure`（HTTPS 或 `COOKIE_SECURE=true`）、`Path=/`
- 有效期默认 72 小时，可配置 1–720
- 退出登录撤销当前会话；禁用账号/重置密码撤销该用户全部会话
- 不使用 localStorage 存放访问令牌

## 4. CSRF

三层防护：

1. 会话绑定 CSRF 令牌（登录/`/auth/me`/改密返回），写请求需带 `X-CSRF-Token`
2. 常量时间比较令牌
3. 校验 `Origin` 与 `Sec-Fetch-Site`，拒绝跨站请求（覆盖登录、注册等未认证写请求）

前端在登录后自动保存令牌并在每次写请求中携带。

## 5. 权限

权限完全由后端判定，前端路由守卫仅用于体验。

| 能力 | 未登录 | 普通用户 | 管理员 |
| --- | --- | --- | --- |
| 查看已发布题目 | ✗ | ✓ | ✓ |
| 提交答案（服务端判分） | ✗ | ✓ | ✓ |
| 查看他人错题/收藏/成绩 | ✗ | ✗ | 仅管理统计 |
| 管理用户/邀请码/题库/考试 | ✗ | ✗ | ✓ |
| AI 出题与审核 | ✗ | ✗ | ✓ |
| 查看答案（管理接口） | ✗ | ✗ | ✓ |

其他约束：

- 管理员不能禁用/删除自己
- 系统至少保留一个可用管理员
- 普通用户不能通过参数修改 `role` 或 `user_id`
- 练习会话、考试记录均校验归属（非本人返回 404）

## 6. 答案保密与判分

- 普通题目接口不返回 `answer`、`explanation`、`content_hash`
- 错题/收藏列表同样不返回答案
- 练习提交后由后端判分，再返回正确答案与解析
- 重复提交返回既有结果，不重复计数
- 考试试卷不含答案；判分只使用服务端快照
- 客户端提交的 `score` 等字段被忽略
- 考试时限由服务端时间判断，保存答案与交卷时都检查
- 交卷幂等：只有 `status='in_progress'` 时才会更新成绩，重复请求返回原结果

## 7. 邀请码

- 使用 `crypto.getRandomValues` 生成 12 位 Crockford Base32（60 bit 熵）
- 仅在创建时返回明文一次，数据库只保存 SHA-256 与掩码
- 校验状态、过期时间、剩余次数
- 占用名额使用单条原子 `UPDATE ... WHERE used_count < max_uses AND status='active' ...`，D1 串行执行，避免并发超额
- 用户创建与使用记录在同一 `db.batch` 中写入；失败时补偿归还名额

## 8. 限流

基于 D1 的固定窗口计数（原子 UPSERT + RETURNING）：

| 场景 | 限制 |
| --- | --- |
| 注册 | 5 次 / 10 分钟 / IP |
| 登录 | 10 次 / 5 分钟 / IP；8 次 / 5 分钟 / 账号 |
| 改密 | 5 次 / 5 分钟 |
| 提交答案 | 120 次 / 分钟 |
| 开始练习 | 30 次 / 分钟 |
| 开始考试 / 交卷 | 15 / 20 次 / 分钟 |
| 考试暂存 | 600 次 / 分钟 |
| AI 生成 | 5 次 / 分钟 + 每日任务上限 |
| 批量导入 | 10 次 / 分钟 |

说明：免费计划下这是尽力而为的防护，不等同于专业 WAF；可在 Cloudflare 控制台叠加 Rate Limiting 规则。

## 9. 输入校验与 SQL 注入

- 所有 SQL 使用参数绑定，不拼接不可信字符串
- 动态 `IN (...)` 仅拼接占位符，值仍绑定
- 排序字段白名单（`newest`/`oldest`/`difficulty`）
- 请求体大小限制：普通 JSON 1MB，导入 6MB，上传 10MB
- 题目结构校验包含：题型、题干、选项数量/重复、答案存在性、难度、来源长度等
- 校验失败返回 `400` 与字段级错误；服务端不透露内部堆栈

## 10. XSS

- Vue 默认对插值转义
- 题干/解析按纯文本渲染（`white-space: pre-wrap`），**不将 Markdown 渲染为 HTML**
- 不使用 `v-html`
- 响应头 CSP：`default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; ...`
- 上传文件名仅用于展示，存储时清洗；不把用户文件名拼进路径

## 11. AI 安全

- API Key 只存在 Worker Secret，前端不读取、不传递
- 只有管理员可调用；每日/单次/输入长度限制；同一时间只允许一个运行中任务
- 返回内容先做 JSON 提取与结构校验，不直接入库
- 校验失败的题目标记 `invalid`，不能通过审核
- 资料文本以"数据"身份放入提示词，系统提示明确要求忽略资料中的指令（提示注入防护）
- 记录模型、Token 用量、任务状态；未返回用量时不伪造
- 错误信息截断且不含 Key
- 审核通过后才写入正式题库；完全重复的题目会被拒绝

**残余风险**：AI 仍可能生成事实错误、答案错误或与知识点不符的题目。系统默认要求人工审核，且不宣称 AI 题目经过权威审核。

## 12. 文件上传

- 仅允许 TXT / PDF / DOCX（按扩展名 + MIME）
- 大小上限 10MB（可配置）
- DOCX 解压限制 20MB，防止压缩炸弹
- PDF：检测加密；无法提取文本（扫描版/特殊字体）时明确报错，不假装成功
- 上传内容只作为 AI 素材，不作为可执行指令
- R2 对象 key 由服务端生成（`ai-sources/<id>/<清洗后的文件名>`），仅管理员可删除
- 资料元数据支持软删除；R2 未绑定时文本入库 D1

## 13. 审计

记录的管理员操作包括：初始化、创建邀请码、禁用/启用/删除用户、重置密码、题目增删改/发布/归档/批量分类/导入、分类增删、考试创建/更新/发布/关闭、AI 生成/审核/重新生成/资料上传删除、公告增删改、系统设置。

审计详情不包含密码、会话令牌、API Key 或完整请求体。

## 14. 响应头与 CORS

- `X-Content-Type-Options: nosniff`
- `Referrer-Policy: no-referrer`
- `X-Frame-Options: DENY` / `frame-ancestors 'none'`
- 生产环境 HSTS（`ENVIRONMENT=production`）
- **不配置宽泛 CORS**：前端与 API 同源；本地开发通过 Vite 代理保持同源

## 15. 密钥管理

- `.env.example` 只含占位符
- 生产使用 `wrangler secret put`
- `.dev.vars` 已 gitignore
- `npm run security:check` 扫描源码与前端产物中的密钥形态、私钥、敏感日志
- 如果怀疑泄露：立即轮换 DeepSeek Key、删除 `ADMIN_SETUP_TOKEN`、撤销全部会话（可清空 `sessions` 表或重置密码）

## 16. 已知限制

1. 未实现 2FA、IP 白名单、密码泄露库比对
2. 限流为 D1 固定窗口，极端并发下可能与预期有少量偏差
3. PBKDF2 迭代次数受 Worker CPU 限制
4. AI 题目质量依赖人工审核
5. PDF 文本提取覆盖常见文本型 PDF，不覆盖扫描件/OCR
6. 管理员为单一角色，无细粒度权限
7. 没有自动化的渗透测试，建议上线前做一次人工安全评估
